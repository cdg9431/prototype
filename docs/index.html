Groundwork (working title)

A professional networking and job platform that fixes what's broken about LinkedIn: no ghosting, no engagement-bait feed, real pay ranges, and no recruiter spam. It starts with a short guided conversation instead of a blank profile.

Prototype

PRD v1

Reachable user

Business students in my program who are actively looking for internships or first jobs. I can reach them directly in class and through my pod, and every one of them has a LinkedIn story.

Before / after workflow

Before (LinkedIn today)

  • Build a profile from a blank page
  • Scroll a feed of posts to find relevant openings
  • Mass-apply to dozens of jobs with vague "competitive" pay
  • Hear nothing back from most of them

After (Groundwork)

  • Answer six quick questions in a guided chat
  • Get a snapshot of target roles and three concrete next moves
  • See a few well-matched openings, each with a real pay range
  • Every application gets a response

One core workflow

  1. User signs in with a name and email.
  2. Scout asks about status, field, goal, work style, skills, and biggest frustration.
  3. The app generates a Career Snapshot: target roles, three next moves, and matched openings.

Non-goals (for now)

  • No social feed. No posts, likes, or algorithmic timeline, by design.
  • No employer side yet. No job posting, recruiter tools, or real listings; openings are sample data.
  • No live AI yet. Scout is a scripted, rule-based chat; connecting a language model comes in a later build.

Build log

What works
Sign-in, the full six-step onboarding chat (buttons or typed answers), and a Career Snapshot that changes based on the user's field, goal, work style, and skills. Progress is saved in the browser.
What I learned
  • How GitHub repos and GitHub Pages work: the whole product can be hosted free as static files.
  • An API key can't go in a public repo or website. Real AI will need a small server to hold the key.
  • The difference between a rule-based bot, an AI chatbot, and an agent. Scout is currently a rule-based bot.
  • Ghosting is a symptom of application volume. Better matching before people apply may matter more than a reply deadline.
What broke or changed
  • Planned live AI onboarding; switched to a scripted chat to keep API keys out of GitHub and ship on time.
  • The Career Snapshot still looks too much like LinkedIn. Redesigning it is a Build 2 priority.
  • "Groundwork" is a placeholder name and will change.
Costs
$0. Static HTML/CSS/JavaScript hosted on GitHub Pages; no paid services or API calls.
Hours
About 3 hours (planning, building, and publishing).
